Embroidery Communicator

Bring your vintage Bernina Artista back to life — send, save, and manage embroidery designs from any modern computer or browser.

A Second Life for a Classic

In the late 90's Bernina released the Artista 180 embroidery machine. At the time it cost 3000 to 4000 US dollars and is still available today second-hand for $800 and up. These robust machines connect to a PC via a serial port (RS232), and Bernina once provided a Windows application to upload embroidery patterns. Sadly that software only runs on Windows XP, so this open-source tool was created to fill the gap — giving these lovely machines a second life on modern Windows, macOS, Linux, and even directly in your browser.

What It Can Stitch Up

🔌

Auto-detect ports

Automatically finds new serial ports the moment a USB-to-Serial adapter is connected.

🧵

Machine info

View details about your connected machine, including its firmware version.

🗂️

Browse patterns

List embroidery patterns stored in both the embroidery module and the PC card.

⬆️

Upload designs

Send embroidery patterns in .EXP format straight to the embroidery module.

⬇️

Download designs

Pull patterns off the embroidery module and PC card, saved as .EXP files.

✂️

Manage storage

Delete embroidery patterns from the embroidery module and PC card to free up space.

Get Stitching

  1. Get a USB-to-Serial DB9 adapter (about $9–$15 online).
  2. Launch the web app, or download the desktop version for your platform below.
  3. Connect the USB-to-Serial cable — the software auto-detects the new port.
  4. Hit Connect to talk to the embroidery machine.
  5. Machine information and existing patterns appear automatically.
  6. Design patterns with InkScape and the Ink/Stitch extension, then export to .EXP to upload.

Bring It Home

Run it now in your browser, or install the desktop app.

Web App (Chrome & Edge) Windows x64 (.zip) macOS (.dmg) Linux x64 (.tar.gz) Linux ARM64 (.tar.gz) All releases & formats

The web version requires a browser with Web Serial support (Chrome or Edge) to connect to a machine over a USB-to-serial adapter.
